# Тихий день 🌿

Личный ежедневник на русском языке: задачи, заметки и прогресс за день.

## Как открыть

Откройте файл `index.html` в браузере после скачивания репозитория. Никакой установки не требуется.

## Где хранятся данные

Задачи и заметки сохраняются локально в браузере (`localStorage`), не передаются на сервер. В приложении есть экспорт и восстановление резервной копии JSON. Если очистить данные браузера, записи могут исчезнуть.

## Безопасность

В первой версии нет регистрации, паролей и серверной аутентификации. Не храните конфиденциальные сведения на общем устройстве.
